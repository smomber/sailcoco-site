Security

Built to stop scraping and AI-assisted abuse, from day one.

Keys are generated at signup, scoped to one account, and revocable instantly from your dashboard.

MCP connections authenticate with OAuth 2.1 and PKCE — no raw keys handed to an AI client.

Limits apply per key and per account, so one leaked key can't be used to bypass a plan's cap.

Anomaly detection flags extraction patterns that look like bulk scraping or automated abuse.

Compatibility

Speaks Signal K, the open marine data standard.

Signal K already runs on thousands of cruising boats — OpenPlotter, Victron Cerbo GX, and more. SailCoCo's API follows the same discovery and data-path conventions, so a boat already running Signal K can pull compliance data the same way it reads depth or wind.

Discovery path

GET /signalk/v1/api/vessels/self/
    sailcoco/compliance
